## Overview

Arden's long-term memory has two canonical layers:

- **Facts** are the durable, source-backed correctness layer. A fact has a
  stable ID, current lifecycle, provenance, and immutable event history.
- **Wiki pages** are the readable, versioned Markdown layer. They organize
  subject context, links, and generated summaries without replacing the facts
  they cite.

The [Areas](/guides/areas) surface is backed by managed wiki pages.

## Facts

Facts are not edited or deleted through a generic record API. To add or correct
knowledge, Arden first prepares an exact change plan, then commits that plan if
the affected facts have not changed. A plan can create, review, amend,
supersede, expire, or retract facts; history and provenance remain available for
inspection.

Use facts for explicit, durable knowledge: preferences, decisions,
relationships, reusable procedures, and significant events. Do not infer facts
from silence or store temporary operational noise.

For exact evidence, Arden searches facts and can read a fact or its event
history. Facts due for evidence-based review are listed separately; a review
does not change a fact by itself.

## Wiki context

Arden automatically receives a bounded resident wiki context from `README.md`,
`directives.md`, `me.md`, and `profile.md`, when those pages are present. For a
substantive prompt, it may also receive a small set of relevant indexed wiki
pages.

The agent can browse the managed wiki by directory, read one page by an exact
ID, path, title, or alias, and inspect its outgoing links and backlinks. Wiki
pages are versioned, so reads identify both the page version and repository
head.

Only an explicit automation may use `publish_wiki_generated` to update a page's
generated region. It must first read the page and provide the exact version and
repository head; it cannot overwrite user-managed prose.

## Desktop and API

The desktop Memory view reads managed wiki pages and the facts they cite. The
[Facts and Wiki API](/api-reference/memory) exposes read-only fact access and
versioned wiki-page management for administrative clients.
