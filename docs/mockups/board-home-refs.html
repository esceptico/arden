Automations run unattended; results land in a triage sidebar with exactly four verbs (diff · Approve · Revise · Reject). The detail that matters: runs with no results are automatically archived — schedule noise costs zero attention.

Linear agent sessions

Six states only (pending/active/error/awaitingInput/complete/stale), derived from observed activity — not agent self-reports. 10s to acknowledge or "unresponsive"; 30min silent → stale. Only awaitingInput/error/stale may claim the human.

Devin — sleeping ≠ blocked

"Sleeping" is a first-class, restful state (auto-wakes on PR comments); waiting-on-you stops the clock. Green confidence proceeds silently; only yellow/red interrupt.

Instrument glanceability

the question: what separates an instrument from a dashboard?

The dark cockpit

When all systems are normal, the panel is dark — nothing is annunciated. Any lit indicator is unmissable because the baseline is silence. Confidence = the absence of annunciation, not a wall of green.

Stephen Few — dashboard pitfalls (PDF)

The canon: single screen, top-left is the #1 question, one display grammar repeated, direct measures with context, "when everything is prominent, nothing stands out."

GitHub merge box

Failing checks itemized on top; passing checks collapse into one aggregate line. Deterministic order, never recency-shuffled.

Vercel deployments list

Dense one-line rows: status word · entity · mono metadata · relative time. Four-word state vocabulary (queued/building/error/ready) everywhere, echoed in the favicon.

Lifeline · Berkeley Mono · Rauno

The aesthetic pole: instrument feel from restraint + typographic rhythm + mono values only where things are measured. Rauno's rule for a 20×/day surface: zero entrance performance; flourish inversely proportional to frequency.

ADHD evidence — the five strongest findings

the question: what does the evidence actually constrain?

WCAG 2.2.2 — Pause, Stop, Hide

Perpetual motion (shimmer, pulse, spinners) parallel to content is the named failure class for attention-deficit users. Liveness must be static evidence: changing step text, elapsed time, last-event age.

Scarr et al. — spatial memory

Reflow and reordering are the empirically confirmed breakers of spatial memory. Fixed slots, deterministic order, reserved space — the layout must never differ between visits.

Mark et al. — the cost of interrupted work

~23 minutes to return to focus after an interruption. Completions should not toast in real time; arriving at the page is the notification moment.

GDS — one thing per page

Field-tested: reducing the screen to one decision measurably improved completion. Users were never bothered by "too little."

W3C COGA — Content Usable

The page states its own purpose; critical items reachable without scrolling; progressive disclosure is first-class but collapsed content must be summarized, never silently hidden.
