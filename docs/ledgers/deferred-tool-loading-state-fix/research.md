# Research

## Surface research

- **Observed run**: session `20260720_094827_005`, model `openai-codex/gpt-5.6-sol`. After the user asked to read pages before edits, reasoning said it would call `wiki_read_page`, but the model emitted `workflow(title="noop", target="none")` plus web search. That workflow spawned five agents; cancellation completion then produced `workflow(title="oops", target="no")`.
- **Repositories**: Arden `7ce7146`; Codex `95637f7`; Claude Code leak `4b9d30f`; Hermes `cb06017`; Letta `b76da90`; OpenCode `1754480`.
- **Official docs**: OpenAI tool search and conversation state; Anthropic tool search and tool references, accessed 2026-08-04.

## Conflicts and gaps

- Codex deferred world state is experimental and namespace-level; Arden should track tool identity/schema hash to catch changes inside a namespace.
- OpenCode relies on MCP `tools/list_changed`; a server that fails to notify can leave its cache stale.
- No implementation or model-level end-to-end regression has been run yet.

## Supporting material

- Targeted current tests passed before planning: three OpenAI/deferred tests and one Anthropic duplicate-loader test. This proves the duplicate behavior is intentional/current, not correct.
